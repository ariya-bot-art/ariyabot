✨ Ariya Bot Privacy Policy

Effective Date: September 9, 2026

Ariya ("the Bot") is committed to protecting user privacy. This Privacy Policy outlines what data is collected, how it is stored, and your rights regarding your data.

1. Data We Collect & Store

  • User & Guild Identifiers: Discord User IDs and Server (Guild) IDs to bind data to users and servers.
  • Economy Data: User coin balances (used for /balance and /give).
  • Moderation History: Warning records, kick/ban logs, and infraction history (used for /warn).
  • Challenge Data: Challenge completion status and leaderboard standings (used for /challenge).
  • Voice Channel Data: Channel configurations created via Join to Create (used for .v commands).
  • AI Conversation Context: Temporary chat history used by /chat to maintain memory across interactions.

2. How Data Is Used

  • To maintain user balances, leaderboards, moderation history, and voice channel controls.
  • To provide context-aware AI responses using the Google Gemini AI API.
  • Data is never sold, rented, or shared with third parties for marketing purposes.

3. Third-Party Data Processing

AI features (/chat, /vibe, /summarize, /newspaper) send text prompts to the Google Gemini API for natural language processing. No personal identifiers (like usernames or raw user IDs) are attached to external API prompts.

4. Data Retention & Deletion

  • Data is stored securely until requested for deletion or until Ariya is removed from a server for more than 30 days.
  • Users can request complete data deletion at any time by joining our Support Server or contacting the bot owner.
